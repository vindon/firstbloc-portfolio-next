# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Use GitHub's **Report a vulnerability** action in this repository's Security
tab to create a private security advisory. Include the affected URL or
component, steps to reproduce, potential impact, and any relevant logs or
screenshots. Avoid including personal data or secrets in the report.

If private vulnerability reporting is unavailable, use a contact method listed
on the maintainer's GitHub profile to request a private channel. Do not include
vulnerability details until a private channel is available, and do not publicly
disclose the issue until the maintainer has had a reasonable opportunity to
investigate and coordinate a fix.

## Response and supported versions

The maintainer aims to acknowledge reports within five business days and will
coordinate next steps and disclosure timing with the reporter. This is a
best-effort response target, not a guaranteed service level.

Security fixes are generally made against the latest version deployed from
`master`. Older versions are not supported.
